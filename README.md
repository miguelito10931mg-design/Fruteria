# Mi Frutería — Tienda Online PWA

Tienda funcional para frutería/verdulería con catálogo, carrito, checkout, pedidos por WhatsApp, panel admin y PWA instalable.

**Sin Firebase por ahora.** Persistencia con IndexedDB. Arquitectura preparada para migrar cambiando 1 archivo.
